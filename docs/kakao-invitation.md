# 카카오톡 초대 공유 확인

초대 공유는 사진 없는 카카오 텍스트 템플릿을 사용합니다. 본문 링크와 ‘초대받은 방 들어가기’ 버튼은 모두 `VITE_SITE_URL/invite/초대토큰`을 엽니다. 토큰이 준비되지 않았으면 전송하지 않습니다.

## 배포 설정

- `VITE_KAKAO_JS_KEY`: 카카오 앱의 JavaScript 키. REST API 키나 어드민 키를 넣지 않습니다.
- `VITE_SITE_URL`: 수신자가 접속할 실제 HTTPS 프런트엔드 주소. 비우면 현재 기본 배포 주소인 `https://43-201-73-60.sslip.io`를 사용합니다.
- 카카오 앱 관리 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인: 공유 버튼을 누르는 사이트의 도메인을 등록합니다. 로컬 테스트 시 로컬 접속 주소도 등록합니다.
- 같은 카카오 앱의 제품 링크 관리 → 웹 도메인: `VITE_SITE_URL`의 도메인을 등록합니다. 경로와 초대토큰은 코드가 전달합니다. OAuth 로그인 Redirect URI 등록과는 별개입니다.
- Vite 환경변수는 빌드 시 적용되므로 변경 후 개발 서버 재시작 또는 프로덕션 재빌드/배포가 필요합니다.

SDK는 페이지에서 미리 로드합니다. 로딩 중에 누르면 준비 완료 안내 후 다시 누르도록 하여 팝업이 사용자 클릭 밖에서 차단되는 것을 피합니다. SDK 로드/호출 실패 시 초대 문구와 링크 복사를 안내합니다. JavaScript 키가 없으면 기존 기기 공유창을 사용합니다.

## 실제 기기 확인

1. 배포 사이트를 카카오톡 안에서 열고 초대 공유 버튼을 누릅니다.
2. 테스트 채팅방에 새 초대를 보냅니다. 사진 없이 초대 문구와 입장 버튼이 보여야 합니다.
3. 수신 기기에서 본문 및 입장 버튼을 눌러 `/invite/실제토큰`으로 이동하는지 각각 확인합니다.
4. 기존 비참여자 계정으로 방 이름을 확인하고 참여를 완료합니다.
5. 카카오톡 밖의 모바일 브라우저에서도 같은 방식으로 확인합니다.

코드 테스트는 SDK에 전달하는 URL과 로딩 동작을 검증합니다. 카카오 서버의 도메인 허용 여부, 실제 전송, 수신 기기의 이동은 위 절차로 별도 확인해야 합니다. 설정을 고친 뒤에는 새로 보낸 초대로 확인하세요.
