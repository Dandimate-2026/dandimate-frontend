# 개발·배포 API 연결 안내

현재 프론트엔드 코드 기준의 실행 안내입니다. 날짜별 검증 기록과 실제 서버에서 확인하지 못한 범위는 아래 문서를 참고합니다.

## 실행 모드

```sh
npm ci
npm run dev
```

`.env.example`을 `.env.local`로 복사해 필요한 값을 설정합니다.

개발·배포 모두 실제 API와 카카오 로그인을 사용합니다. `VITE_API_BASE_URL`이 비어 있으면 개발 서버의 `/api` 프록시를 사용하고, 배포 빌드는 기본 배포 API를 사용합니다.

로컬 예시 데이터·가짜 로그인·결제 성공 시연과 독립 UI 미리보기는 제거했습니다. 심사용 예시 방은 로그인한 계정에서 [서버 데모 모드](reviewer-demo-integration.md)를 사용합니다.

기본 API 주소는 `https://43-201-73-60.sslip.io/api/v1`이며, [Swagger UI](https://43-201-73-60.sslip.io/swagger-ui.html)에서 공개 명세를 확인할 수 있습니다.

## 인증과 개발 환경

요청은 로그인 세션 쿠키를 포함합니다. 쓰기 요청에는 공통 API 클라이언트가 발급받은 CSRF 토큰을 넣습니다. 필요한 저장·주문 요청의 멱등성 키도 기존 API 함수에서 관리합니다.

로컬에서 로그인·API 연결이 실패하면 카카오 로그인 복귀 주소, 서버 쿠키 정책과 허용 출처를 확인합니다. 로그인 시작은 배포 서버를 사용하므로 `/api` 프록시만으로 모든 로그인 환경이 해결되는 것은 아닙니다. 새 출처에서 검증할 때는 서버 설정을 함께 확인합니다.

같은 카카오 계정은 같은 방의 동일한 멤버입니다. 실제 방장·멤버 시나리오는 서로 다른 계정으로 검증합니다.
