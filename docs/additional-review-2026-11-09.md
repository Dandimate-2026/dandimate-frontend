## 업로드 순서 근거

로컬 백엔드의 `PhotoUploadController.complete`는 `data.photo.status`를 반환한다. `PhotoUploadService`는 변환이 필요한 사진을 PROCESSING 상태로 두고 작업을 생성하며, `EntryService.create`는 READY가 아니면 첫 한마디를 거절한다. 따라서 complete 응답을 무조건 최종 완료로 취급하지 않도록 수정했다. 같은 complete 엔드포인트로 상태를 다시 확인하며 취소·실패·시간 초과에는 미확정 서버 사진을 정리한다.

읽은 로컬 백엔드와 배포 서버 버전이 같다고 가정하지 않는다. 최신 공개 API 명세는 `https://43-201-73-60.sslip.io/openapi/public-api.yaml`에서 내려받아 대조했다. 백엔드 파일은 수정하지 않았다.
